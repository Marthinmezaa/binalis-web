# Política de seguridad

## Versiones soportadas

Solo se mantiene la versión publicada en <https://binalis.com.py> (rama `main`).

## Reportar una vulnerabilidad

**No abras un issue público.** Reportala de forma privada desde
[Security › Report a vulnerability](https://github.com/Marthinmezaa/binalis-web/security/advisories/new).

Incluí, si podés:

- Descripción del problema y su impacto.
- Pasos para reproducirlo (URL, petición o payload).
- Versión o commit afectado.

Se confirma la recepción y se informa el avance del arreglo por el mismo canal. Cuando esté corregido, se publica el aviso y se reconoce a quien lo reportó, si así lo desea.

## Alcance

- El sitio y la función serverless del formulario de cotización.
- La configuración de este repositorio (workflows, dependencias).

Quedan fuera los servicios de terceros (Cloudflare, GitHub, proveedor de correo): reportalos a cada proveedor.
